Problem Analysis
The Ideation Gap Atharv

The Napkin-to-Code Bottleneck

Why brilliant whiteboard and napkin ideas get stuck before reaching the code editor.

Bottleneck 01

The Translation Tax

Developers spend over 70% of early prototype time manually converting hand-drawn whiteboards into manual HTML/CSS boilerplate and Figma frames.

By the time the initial CSS grid is wired up, the spontaneous creative momentum is completely lost.

Result: Sluggish iteration & prototype fatigue
Bottleneck 02

The Text-Prompt Trap

Existing AI tools demand paragraphs of text descriptions. But human layout thinking is fundamentally spatial: describing 2D spatial layouts with words alone causes hallucinations and misaligned layouts.

Explaining nested cards, buttons, and responsive breakpoints in English is painful and error-prone.

Solution: Spatial visual reasoning, not text tokens
Bottleneck 03

Static Dead-End Output

Generic "screenshot-to-code" toys output frozen, dead HTML blocks. Changing a button label or title requires another expensive AI re-generation.

There is no live sandbox, no variable slot bindings, and no mobile/desktop responsive verification.

Need: Live sandboxed component with dynamic props
Our Approach: What if your digital drawing board could directly feed an open multimodal model that speaks native frontend semantics?
The Solution
S2K: Sketch-to-UI Atharv

The S2K Experience: Sketching IS Coding

An authentic digital sketchbook engineered for natural ideation and instant compilation.

  • Tactile Vector Sketchpad: Rough.js pen physics with ballpoint blue, carbon black, and crimson inks that physically re-sketch on hover.
  • Pre-Made UI Component Stamps: Stamp buttons, input fields, badges, cards, tables, and navbars with 8-point resize handles and in-place renaming.
  • Precision Eradicator Mode: Line-segment collision detection deletes only the single touched ink stroke without wiping overlapping lines.
  • Paper Photo Upload: Sketched on a real paper napkin at lunch? Snap a phone photo and upload it directly onto the board for compilation.
  • Napkin Wireframe Presets: 1-click loading for Hero Sections, Auth Cards, Pricing Tables, and Data Grids.

Why Google Gemma 4?

Open-weights multimodal vision, robust ecosystem integrations, and resilient architecture.

Visual Reasoning

Spatial Visual Grounding

Gemma 4 natively understands 2D spatial hierarchy. It differentiates between outer modal frames, nested form inputs, buttons, and navigation bars from rough freehand doodles.

It interprets visual grouping, margins, and alignments without needing explicit CSS coordinate instructions.

Native @google/genai SDK
Zero Downtime

Dynamic Model Fallback

Primary engine: gemma-4-31b-it for maximum semantic depth and nuanced component structure.

Automatic failover: gemma-4-26b-a4b-it smoothly steps in if rate limits or quota spikes occur, ensuring non-stop uptime during live judging.

Automated Failover Router

Open-Source Integration

Built on open-weights foundation with universal provider flexibility: seamlessly connects to NVIDIA NIM open models, local Ollama/vLLM endpoints, or cloud providers.

Live Sandbox Purvanshi

Live Sandbox & Reactive Props

Zero-latency component customization without re-calling the AI model.

  • Automated Prop Discovery: Automatically identifies customizable variables (e.g., title, buttonText, variant) in generated HTML.
  • Sub-10ms Live Binding: Edit values in the props table ➔ live iframe updates in real time with zero network latency and zero token cost!
  • Multi-Device Viewport Switcher: Instant 1-click preview across Desktop (100%), Tablet, and Mobile (375px) viewports.
  • One-Click Code Export: Clean, copyable semantic HTML5 markup ready to paste directly into a production repository.
Why This Matters: It transforms Sketch2Kernel from a static mock generator into a living UI testbench.

Security & Reliability
Defense-in-Depth Purvanshi

Production Resilience & Security

Bulletproof rate limiting, self-healing parsers, and strict iframe sandbox isolation.

Quota Armor

29 RPM Rate Limiting

Rolling sliding-window queue in lib/gemini-rate-limiter.ts. Automatically delays requests approaching quota limits, preventing ugly 429 Too Many Requests lockouts.

Zero 429 Failures
Self-Healing

Resilient Extractor

lib/json-extractor.ts handles varied model output: self-repairs broken JSON quotes, markdown code fences, raw outer HTML, and git diffs without throwing fatal exceptions.

Multi-Format Parser
XSS Protection

DOMPurify & Isolation

Passes all markup through DOMPurify, stripping <script>, onerror, and javascript: URIs. Rendered in an isolated iframe with restricted sandbox permissions.

Zero Origin Leakage
Hackathon Durability: While other projects crash when API limits get hit during live judging, Sketch2Kernel stays rock-solid due to client-side queuing and automated fallback.
